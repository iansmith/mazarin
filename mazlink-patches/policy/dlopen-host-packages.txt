# Mazlink dlopen — host-resident packages.
#
# Every Go import path listed here is resolved against the host at
# plugin load time (via UNDEF dynsym + JUMP_SLOT/GLOB_DAT relocations)
# rather than shipped inside the plugin image. Anything NOT listed
# here ships as ordinary code inside each plugin's own ELF.
#
# Format:
#   - one import path per line
#   - trailing "/..." means "this package and all subpackages"
#   - "#" starts a line comment; blank lines ignored
#
# Read by: mazlink's internal linker at build time (via
# -dlopen-host-packages=<path>), and by the host-export side to decide
# which symbols to mark GLOBAL+DEFINED in the host binary's dynsym.
#
# See design/MAZARIN-DLOPEN.md §2 for the full rationale and §6 for the
# expansion rules — every addition beyond this starting set should come
# with a short note here explaining what drove it.

# ---------------------------------------------------------------------
# mazdl / mazhost — the one-generic-shepherd must own all plugin loading.
#
# Rationale: mazdl carries package state (modules, globalSyms, modulesMu)
# that tracks every loaded .maz in the process. If each plugin carried
# its own copy of mazdl, plugin-side calls to mazhost.LoadMazBootstrap
# would populate a *different* module table than the one the shepherd
# seeded via RegisterHost — plugin-of-a-plugin would fail to resolve
# host runtime symbols. Making mazdl/mazhost host-resident keeps a
# single shared registry: the generic shepherd publishes the runtime,
# and any subsequent plugin load (rachel → fontsvc, fs → ...) walks the
# same map.
# ---------------------------------------------------------------------

mazzy/mazarin/mazdl
mazzy/mazarin/mazhost

# ---------------------------------------------------------------------
# fsclient — must be host-resident to keep all FSClient interface methods
# reachable. The host binary only calls Connect/SetRespRing/GetRespCh
# directly; plugins (linux, rachel, fontsvc) call Open/Close/Read/Write/
# Stat/Mkdir/etc. through the FSClient interface itab. Without host
# residency, deadcode drops the unused methods, leaving "unreachable
# method called" stubs in the itab.
# ---------------------------------------------------------------------
